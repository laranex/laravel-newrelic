New Relic for Laravel: ship logs to New Relic Logs and report each Octane request as a named transaction. Built for humans and AI agents.

## Documentation

Full documentation, including installation, usage and the AI agent skill, lives at **[laranex.vercel.app/laravel-newrelic](https://laranex.vercel.app/laravel-newrelic)**.
